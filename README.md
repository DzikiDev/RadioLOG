# RadioLOG 📻

RadioLOG to bezpłatna aplikacja na Androida do prowadzenia dziennika łączności radiowych QSO.

Obsługuje pasma 2 m, 70 cm, CB oraz PMR 446.

## Najważniejsze funkcje
- Zapisywanie i przeszukiwanie łączności QSO
- Wyszukiwanie korespondentów
- Mapa miejsc łączności i obliczanie odległości
- Historia i statystyki
- Lokalizacja GPS
- Kopie zapasowe danych

Aplikacja powstała z własnych potrzeb krótkofalowca i jest udostępniana bezpłatnie, bez reklam.
